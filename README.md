# AI WhatsApp Recipe Bot

An AI-powered WhatsApp chatbot that generates personalized recipes based on the ingredients users have on hand. Built with **FastAPI**, **Twilio**, **PostgreSQL**, and **Groq LLM**, the bot remembers user dietary preferences (such as vegetarian or vegan) and delivers tailored recipe suggestions through a natural WhatsApp conversation.

## Features

* 🥗 Generates recipes from user-provided ingredients
* 🤖 AI-powered recipe generation using Groq
* 💬 Works directly on WhatsApp via Twilio
* 🥕 Remembers user dietary preferences
* 🗄️ Stores user data with PostgreSQL
* ⚡ Built with FastAPI for high performance
* 🐳 Docker support for easy deployment

## Tech Stack

* Python
* FastAPI
* PostgreSQL
* SQLAlchemy
* Alembic
* Twilio WhatsApp API
* Groq API
* Docker
